# QCBlender 高级分析结果可视化需求调查（第四版预测试草案）

版本日期：2026-09-27

预计用时：6–9 分钟，待认知访谈核验。

## 给填写人的说明

本调查面向过去 12 个月亲自生成、处理、解读，或实际使用过量子化学高级分析结果的人（例如分子间相互作用、分子表面或轨道相互作用分析）。不要求使用过某个指定软件。

QCBlender 是仍在开发中的 Blender 扩展。本问卷收集用户对量子化学结果输入、可视化输出和交互操作的需求；题目不代表功能承诺。

请按过去 12 个月的实际工作回答。不清楚文件或软件名称时可选“不确定”。请勿填写姓名、单位、联系方式、未获准公开的研究数据或其他敏感信息。

### Q12｜希望完成的输入与可视化任务

**设想把您已有的分析结果用于制作可视化，哪些“输入数据 → 目标视图”组合最符合您的工作？请选择至多 3 项。**

- 题型：多选，最多 3 项
- 必答：是
- 选项：
  - 分子结构 + IGMH/IRI/NCI 相互作用场与着色场网格（如两份 Cube；描述弱相互作用区域）→ 着色等值面（场值达到指定阈值形成的表面）和对应散点图
  - 分子结构 + ESP 网格或表面点/属性表（ESP 是静电势）→ 静电势着色表面、极值点和面积统计
  - 分子结构 + QTAIM/AIM 临界点、键路径及属性文件（分析电子密度的拓扑特征）→ 点线叠加和属性查询
  - NBO/E(2) 记录（自然键轨道及供体—受体相互作用数据，如 Gaussian 输出）→ 可筛选的相互作用表及相关原子信息
  - IRC 分步结构文件（如 Gaussian `.fchk`）、能量和 Mayer 键级数据（键级描述原子间成键强弱）→ 分步构型浏览及能量/键级曲线
  - 参考分子结构 + ETS-NOCV 能量分解表和带正负值的形变密度网格 → 可选择 NOCV pair（成对的轨道相互作用结果）的表格与表面
  - 分子结构 + 激发态空穴/电子或跃迁密度网格 → 同一结构上的成对分布或跃迁密度视图
  - 其他输入数据与目标视图组合
  - 暂无上述需求
  - 不确定
- 互斥规则：“暂无上述需求”和“不确定”各自与其他选项互斥。
- 变量：`input_output_workflow_priority`
