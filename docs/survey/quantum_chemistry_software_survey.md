# QCBlender 高级分析结果可视化需求调查（第三版预测试草案）

版本日期：2026-09-23

预计用时：6–9 分钟，待认知访谈核验。

## 给填写人的说明

本调查面向过去 12 个月亲自生成、处理、解读，或实际使用过量子化学高级分析结果的人（例如分子间相互作用、分子表面或轨道相互作用分析）。不要求使用过某个指定软件。

QCBlender 是仍在开发中的 Blender 扩展，当前为 0.0.1 开发验收候选，主要面向 Gaussian 计算结果与分子空间场的可视化。独立用户验收和对外发布尚未完成。本问卷讨论一种可能的后续工作流：把已有分析工具生成的结果文件导入 Blender，建立可编辑、可复核的视图。高级分析结果的导入与展示仍处于需求和开发候选阶段；问卷不是对现有功能、科学正确性或性能的评价，也不构成功能承诺。

请按过去 12 个月的实际工作回答。不清楚文件或软件名称时可选“不确定”。请勿填写姓名、单位、联系方式、未获准公开的研究数据或其他敏感信息。

### Q02｜实际涉及的分析结果

**过去 12 个月，您实际涉及过哪些分析结果？请选择所有适用项。**

- 题型：多选
- 必答：是
- 选项：
  - 分子间相互作用区域分析，如 NCI、IRI、IGMH（显示分子接触或弱相互作用区域）
  - ESP 分子表面分析（静电势在分子表面的分布、极值或面积统计）
  - QTAIM/AIM 分析（电子密度的临界点、键路径或原子盆）
  - NBO/E(2) 分析（自然键轨道及供体—受体相互作用）
  - IRC/反应路径或 Mayer 键级（反应过程中的构型、能量或键级变化）
  - EDA/ETS-NOCV 分析（相互作用能量分解及对应的形变密度）
  - 激发态分析（激发后电子与空穴的空间分布或跃迁密度）
  - 其他高级分析结果
- 变量：`advanced_result_types_12m`

## B. 后续导入与展示需求

以下题目讨论把**已经由外部软件生成的分析结果**导入 QCBlender 后查看和制作可编辑视图（例如读入空间网格、临界点、键路径或表格）。本问卷不假设 QCBlender 会运行 Multiwfn 或内置这些分析算法。

### Q10｜现有流程中的主要困难

**从取得分析结果到完成可用图像或三维视图，哪些问题最影响您的工作？请选择至多 3 项。**

- 题型：多选，最多 3 项
- 必答：是
- 选项：
  - 结果文件缺失，或不同格式之间转换困难
  - 不同文件与正确构型、原子顺序或反应步难以对应（例如多个文件中的第 1、2 个原子是否代表同一原子）
  - 物理量、单位、自旋、轨道或分析参数容易丢失或误读
  - 多个空间场、点、路径或表格难以组合展示
  - 等值面（场值达到指定阈值形成的表面）、切片、颜色范围或图例难以调整
  - 分析来源与成图设置难以保存或复核
  - 大型网格、项目迁移或团队分享困难
  - 目前没有明显困难
  - 不确定
- 互斥规则：“目前没有明显困难”和“不确定”各自与其他选项互斥。
- 变量：`analysis_viz_pain_points`

- 题型：单选
- 必答：是

  - 完全没有帮助
  - 帮助较小
  - 一般
  - 帮助较大
  - 帮助很大
  - 信息不足，无法判断
- 变量：`external_result_import_value`

### Q12｜优先支持的分析结果

**若后续优先完善外部分析结果的导入和展示，哪些结果最值得先做好？请选择至多 3 项。**

- 题型：多选，最多 3 项
- 必答：是
- 选项：
  - IGMH/IRI/NCI 等相互作用场及其着色场或散点图（呈现弱相互作用区域及对应数值）
  - ESP 表面极值、逐点查询和面积统计（检查表面静电势及其分布）
  - QTAIM/AIM 临界点、键路径及属性（展示电子密度拓扑特征）
  - NBO/E(2) 轨道与供体—受体相互作用记录
  - IRC 构型/能量路径及与步骤关联的 Mayer 键级
  - ETS-NOCV 能量表及对应的 NOCV 形变密度场
  - 激发态空穴/电子或跃迁密度场
  - 其他已有的标量/矢量网格场及离散结果
  - 暂无上述需求
  - 不确定
- 互斥规则：“暂无上述需求”和“不确定”各自与其他选项互斥。
- 变量：`future_analysis_priority`

### Q13｜优先完善的展示方式

  - 在分子结构上叠加临界点、键路径或其他空间对象
  - 联动查看数据表、点选信息和能量/统计曲线
  - 显示体积场、截面或选定区域
  - 比较多步构型、空间场或分析结果
  - 制作模式、路径或多帧结果的动画
  - 调整节点、材质、图例并保存可编辑的 Blender 工程
  - 暂无上述需求
  - 不确定
- 互斥规则：“暂无上述需求”和“不确定”各自与其他选项互斥。
- 变量：`visualization_priority`

## 研究者实施与分析说明（不向受访者展示）

- Q01 是唯一筛选分支。选择“否”或“不确定”后显示简短感谢语并结束；被筛除或跳过的答卷不计为“没有需求”。
- Q02 测量近 12 个月实际接触的分析类型；Q03 区分亲自分析、整理数据、接收结果和制作图像；Q04 用于区分低频任务与常规工作流。
- Q06、Q07 和 Q08 分别记录上游电子结构计算程序、分析工具与结果查看/制作软件。Multiwfn 可以在不同阶段使用，按受访者实际用途填写，不据此推断它的唯一角色。
- Q09 区分波函数、已计算网格场和离散/表格结果。扩展名只是文件线索，不能单独证明其物理量、单位、构型或科学含义。
- Q10–Q14 测量现有困难、外部结果导入设想的相关性、分析结果/展示优先级和来源核验需求；它们不构成对功能实现、性能或科学正确性的验证。
- Q12/Q13 多选百分比使用有效答卷作分母；按 Q02 分析类型、Q03 参与角色、Q06/Q07 软件和 Q09 可得数据分层报告。便利样本只报告本样本比例，不推断总体市场份额。
- Q15 只收集周期体系与多构型/轨迹的扩展兴趣，不据此承诺近期支持范围。
- 预计 6–9 分钟尚未核验。正式发放前建议对 10–15 名不同角色的高级分析用户开展认知访谈，检查“高级分析”、文件类别和软件阶段的理解、筛选分支、实际完成时间及隐私提示。
