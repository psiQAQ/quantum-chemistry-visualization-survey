# QCBlender 量子化学结果可视化需求调查（第二版预测试草案）

版本日期：2026-09-22

预计用时：6–9 分钟，待预测试核验。

## 给填写人的说明

Blender 中已有 MolecularNodes，主要面向结构生物学数据的导入与展示；ChemBlender 可展示分子、晶体及部分计算结果。QCBlender 正在探索另一种工作流：在一个 Blender 扩展中读取量子化学输出、从可用波函数数据生成空间场、保留计算条件与数据来源，并用可编辑的几何节点制作图像和动画。本调查希望了解您实际如何获取、检查和展示计算结果，以及这一设想能否解决您的问题。

QCBlender 仍在开发，尚无正式发布版本。拟定首版以 Gaussian 的 Log、FCHK 和 Cube 文件为输入，面向非周期分子的常见 HF/DFT 计算结果；其他程序和高级分析属于后续方向。您无需使用过 Blender 或了解文件格式，也无需判断尚未发布的软件性能。请根据过去 12 个月的实际经历作答；不清楚技术细节时可选“不确定”。请勿在留言中填写姓名、单位、联系方式或未获准公开的研究数据。

## C. QCBlender 设想与开发顺序

以下题目讨论**拟开发的功能**，不是对现有 QCBlender 软件的使用评价。首版计划用单个 Blender 扩展读取 Gaussian Log/FCHK/Cube；在数据足够且受支持时生成轨道、电子密度、自旋密度或静电势等空间场，并以可编辑节点控制展示。计算条件、来源和显示参数随结果保留。首版目标平台是 Windows x64 与 Blender 5.1.1。

## 研究者实施与分析说明（不向受访者展示）

- Q01 是唯一筛选分支。选择“过去 12 个月没有相关经历”后显示简短感谢语并结束；不得将其后跳过的题目计为“没有需求”。其余受访者均可进入 Q02–Q17。
- 在平台中落实所有互斥规则和多选上限。“不确定”“没有需求”与具体经历或需求分开统计；Q17 保持可选。
- Q05 的 `.chk`、`.fchk` 和 `.cube` 是不同可得性：仅有 `.chk` 不代表可直接读取波函数，也不代表受访者拥有已计算场。Q13–Q16 测量对设想的判断，不解释为实际使用、性能或科学正确性的证据。
- 按 Q01 参与方式、Q04 程序、Q05 文件可得性及 Q11–Q12 Blender 条件分层；多选题报告受访者百分比和有效分母。便利样本只报告“本样本中的比例”，不外推为总体市场份额。
- 用 10–15 人认知访谈覆盖亲自计算者、计算合作者、委托方和结果使用者；核查开场定位是否诱导、术语理解、筛选逻辑、留言隐私及实际完成时间。6–9 分钟只是设计目标，尚未验证。
- 发放前必须替换两处共建入口占位标记，核对仓库已开放且 Discussion 可用。若另招募访谈，联系方式须通过独立渠道收集，不与问卷答卷合并。
- 本版延续第一版已核验全文支撑的工作流、数据表示、可视化与数值核验构念；新项目范围依据 QCBlender 的首版设计。MolecularNodes、ChemBlender 的介绍只说明各自主要用途，不构成“Blender 没有其他量子化学工具”的排他性判断。既有先例与证据见[跨主题文献精读关键发现](../research/literature_review_cross_cutting_findings_2026-07-19.md)及[第一版问卷](quantum_chemistry_software_survey_draft_2026-07-19.md)。
